# CS2 Upgrader Online

Этот репозиторий содержит игру и сервер комнаты. GitHub хранит код, а постоянно работающий сервер запускается на веб-хостинге, например Render.

## Публикация через GitHub и Render

1. Создайте на GitHub новый **публичный репозиторий** `cs2-upgrader-online`.
2. Загрузите в корень репозитория `index.html`, `server.js`, `package.json` и `render.yaml`.
3. На [Render](https://render.com/) войдите через GitHub, выберите **New → Web Service** и этот репозиторий.
4. Runtime: **Node**; Build Command: `npm install`; Start Command: `npm start`. Выберите доступный вам тариф и создайте сервис.
5. Когда сервис станет доступен, откройте выданный Render HTTPS-адрес. В игре откройте **Онлайн** и нажмите **Подключиться**. Адрес сервера подставится автоматически.
6. Передайте друзьям HTTPS-адрес сервиса. Для разных игроков нужны разные ники.

Render задаёт порт через переменную окружения `PORT`. Сервер слушает этот порт и отдаёт игру по `/`.

## Локальный запуск

Нужен Node.js 18 или новее. Выполните `npm start`, затем откройте `http://localhost:8765`.

## Что хранится на сервере

Онлайн комната, чат, счёт матча и рейтинг находятся в памяти сервера и сбрасываются после его перезапуска. Скины, монеты, профили и админские роли остаются в браузере каждого игрока. Это игровая комната, а не защищённая система аккаунтов. Для постоянного общего прогресса понадобятся база данных и вход в аккаунт.
